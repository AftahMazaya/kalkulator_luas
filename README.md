# 📐 Kalkulator Luas Bangun Datar (C++)

Program C++ sederhana berbasis terminal untuk menghitung luas berbagai macam bangun datar secara otomatis. Cocok untuk tugas sekolah, belajar dasar pemrograman C++, atau sekadar referensi ngoding!

## 🚀 Fitur Program
Program ini menggunakan sistem menu interaktif dengan fitur pembersihan layar (Clear Screen) agar output terminal tetap rapi. Bisa menghitung:
- Luas Persegi
- Luas Persegi Panjang
- Luas Segitiga
- Luas Lingkaran
- Luas Trapesium
- Luas Jajar Genjang

## 💻 Cara Menjalankan (How to Run)
1. Pastikan kamu sudah menginstal compiler C++ (seperti **MinGW/GCC**).
2. Clone repositori ini atau download file `kalkulator_luas.cpp`.
3. Buka terminal/Command Prompt di folder tempat file berada.
4. Compile kode dengan perintah:
   ```bash
   g++ kalkulator_luas.cpp -o kalkulator_luas
